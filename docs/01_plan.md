# Project Plan

## 📌 Objective
The objective of this project is to design and implement a lightweight CSV-based database and query engine using C++. The system will simulate basic database functionalities such as data loading, querying, and filtering.

---

## 🎯 Goals
- Parse CSV files into structured data
- Store data in memory efficiently
- Implement basic query operations (SELECT, WHERE)
- Design modular and maintainable code
- Provide clear documentation and testing

---

## 🗂 Development Phases

### Phase 1 – Planning
- Define project scope and objectives
- Identify core features
- Design system structure

### Phase 2 – Design
- Define modules (parser, storage, query engine)
- Plan data structures
- Outline interaction between components

### Phase 3 – Implementation
- Implement CSV parser
- Implement data storage
- Implement query processing

### Phase 4 – Testing
- Test CSV parsing
- Test query correctness
- Handle edge cases (empty file, invalid format)

### Phase 5 – Documentation
- Write project documentation
- Finalize report

---

## 🧠 Tools & Technologies
- Language: C++
- Compiler: g++
- Version Control: Git & GitHub
