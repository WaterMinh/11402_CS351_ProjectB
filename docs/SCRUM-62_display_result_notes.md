# SCRUM-62 Display Final Result Notes

## Project

Project B: Student Grade Calculator

## Purpose

This story focuses on displaying the final result to the user. After the system calculates the grade, it should show the result clearly and make it easy to understand.

## Display Requirements

The final result should include:

- Student name
- Total score
- Average score
- Final letter grade
- Error message if the input is invalid

## Valid Output Example

Student Name: David Chen  
Total Score: 333.0  
Average Score: 83.3  
Letter Grade: B

## Invalid Output Example

Error Message: Invalid input. Score must be between 0 and 100.  
Final Score: Not calculated  
Letter Grade: Not assigned

## Notes

The output should be simple and readable. The user should immediately understand the student's final result without checking the calculation manually.
